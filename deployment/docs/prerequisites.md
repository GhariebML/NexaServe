# Prerequisites

Target baseline: Ubuntu Server 24.04 LTS, x86_64, 8+ vCPU recommended, 32 GiB RAM baseline, 100 GiB free disk, supported NVIDIA GPU around 12 GiB VRAM. Actual model load, inference and concurrent capacity must be tested on the supplied GPU; baseline is not a performance guarantee.

Ministry IT supplies SSH/admin access, approved apt/image/model mirrors, DNS/FQDN, TLS, firewall/allowlists, NTP, secret vault, backup destination/retention, monitoring contacts, WhatsApp test account and approved DEBI knowledge source. Online requires allowed registries/source websites. Offline requires the generated Docker/Ollama archives plus approved host packages; driver/toolkit installation must not rely on untrusted installers.

Follow the numbered prerequisites and stop gates in `../DEPLOYMENT.md`.
