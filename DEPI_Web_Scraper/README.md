# DEPI Web Scraper

This project scrapes the live DEPI website, extracts structured content from the rendered pages, and produces clean JSON files optimized for n8n and downstream RAG workflows.

## What it does

- Renders pages in a headless browser to capture content generated by JavaScript
- Extracts page titles, headings, text sections, and links
- Extracts FAQ content from the accordion UI
- Saves a final dataset as JSON files for n8n automation and retrieval pipelines
- Produces RAG-ready records from page sections and FAQ entries

## Project structure

- `main.py` — runner entry point
- `scraper/config.py` — target page URLs and output folders
- `scraper/browser.py` — Playwright render layer
- `scraper/extractor.py` — HTML/text extraction logic
- `scraper/cleaner.py` — normalization and deduplication
- `scraper/scraper.py` — orchestration and output generation
- `scraper/validator.py` — JSON validation helpers
- `data/final/` — generated JSON outputs
- `tests/` — regression tests

## Run locally

1. Open a terminal in the project root.
2. Create and activate a virtual environment if needed.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the scraper:

   ```bash
   python main.py
   ```

5. Generated files will appear in `data/final/`.

## Output files

- `depi_data.json` — complete dataset with pages, FAQs, and documents
- `pages.json` — page list
- `faqs.json` — FAQ records
- `documents.json` — extracted document metadata/text
- `depi_rag.json` — RAG-ready records

## Notes

The site relies on client-side rendering, so direct HTML fetches are insufficient for reliable extraction. The scraper uses Playwright to render the DOM before parsing, which is the key to acquiring the real page content.
